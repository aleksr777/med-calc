# Медицинский калькулятор

Адаптивный сайт для расчёта растворов и пересчёта доз. Чистые HTML, CSS и JavaScript: без сборки, сторонних библиотек, внешних шрифтов и серверной обработки данных.

## Страницы

| Файл | Калькулятор |
| --- | --- |
| `index.html` | Приготовление растворов: исходная концентрация и объём → связанные поля нужной концентрации и конечного объёма → объём растворителя |
| `infusion-rate.html` | Вес → одно поле концентрации с выбором единиц → три поля для массовой дозы либо два поля для активности и мл/час |

Откройте `index.html` в браузере. Обе страницы работают и при открытии с диска без подключения к интернету. Старые адреса `mg-hour-to-mcg-kg-min.html` и `mcg-kg-min-to-mg-hour.html` перенаправляют на единую страницу. Для размещения на статическом хостинге загрузите HTML-файлы и папку `assets`, сохранив структуру каталогов. Все пути относительные, поэтому сайт работает в подкаталоге, в том числе на GitHub Pages.

Разработка ведётся в ветке `develop`.

## Поведение

- Тёмный адаптивный интерфейс для ПК, планшетов и телефонов. Внутри полей нет текстовых подсказок.
- Автоматический пересчёт, сброс и копирование результата. Кнопки ручного расчёта нет на обеих страницах. Связанные поля разделены знаком «=», в том числе при вертикальном расположении на телефонах.
- Результат приготовления раствора содержит общий вывод: объём и концентрацию исходного раствора, объём растворителя, полученный объём и концентрацию. Этот вывод включается и в копируемый результат. Массовые концентрации в нём указаны в мг/мл, активность — в выбранных ЕД/мл или МЕ/мл.
- На обеих страницах доступны ЕД/мл и МЕ/мл наряду с мг/мл, мкг/мл и %. При приготовлении раствора нужная концентрация автоматически использует те же единицы активности; количество препарата выводится в ЕД или МЕ. Калькулятор не переводит ЕД в МЕ, активность в массу или проценты. При смене группы единиц целевые поля или скорости и результат очищаются, чтобы заново ввести нужное значение.
- Поля допускают только цифры и один десятичный разделитель: точку либо запятую. Ограничение действует при наборе, вставке и перетаскивании текста. Недопустимая вставка отклоняется целиком. Метки, единицы измерения и сообщения об ошибках расположены вне вводимого значения.
- Пустые, некорректные и отрицательные значения не дают результата; масса, концентрация и объёмы должны быть больше нуля. Для дозы допускается ноль.
- Промежуточные вычисления не округляются. Связанные поля показывают до 12 значащих цифр без разделителей тысяч и без экспоненциальной записи. Исходное поле сохраняет введённый текст. В блоке результата приготовления растворов используется до 6 знаков после запятой.
- Введённые данные обрабатываются только в браузере, не сохраняются и никуда не отправляются. Между страницами значения не переносятся.
- Поля подписаны, поддерживаются клавиатурная навигация, ссылка перехода к содержимому, сообщения для экранного диктора и уменьшение анимаций по настройкам устройства.
- В приготовлении растворов поля нужной концентрации и конечного объёма доступны только после ввода положительной исходной концентрации и исходного объёма. Ввод в любое из двух целевых полей сразу рассчитывает второе и объём растворителя. Изменение исходных данных сохраняет последнее введённое целевое значение. Очистка или ошибка исходных данных очищает и блокирует целевые поля. Недопустимая целевая концентрация или объём сохраняется для исправления; связанное поле и результат очищаются.
- На странице скорости сначала введите положительный вес пациента. Затем станет доступно одно поле концентрации с выбором единиц. Для мг/мл, мкг/мл и % доступны мкг/кг/мин, мг/час и мл/час. Для ЕД/мл доступны только ЕД/час и мл/час; для МЕ/мл — МЕ/час и мл/час. Ввод в любое видимое поле сразу пересчитывает остальные. Вес сохраняет блокировку этапов во всех режимах, но не участвует в пересчёте активности в мл/час.
- При изменении корректного веса или концентрации последнее отредактированное поле скорости остаётся исходным. При очистке или недопустимом значении веса концентрации и скорости очищаются и блокируются. При очистке или недопустимом значении концентрации очищаются и блокируются скорости. Недопустимая скорость очищает остальные скорости, сохраняя возможность исправить ввод. Ноль допустим для скорости.

## Формулы

```text
мкг/кг/мин = мг/час × 1000 / (60 × масса в кг)
мг/час = мкг/кг/мин × масса в кг × 60 / 1000

мг/час = мл/час × концентрация готового раствора в мг/мл
мл/час = мг/час / концентрация готового раствора в мг/мл
мл/час = мкг/кг/мин × масса в кг × 60 / (1000 × концентрация в мг/мл)

ЕД/час = мл/час × концентрация в ЕД/мл
мл/час = ЕД/час / концентрация в ЕД/мл
МЕ/час = мл/час × концентрация в МЕ/мл
мл/час = МЕ/час / концентрация в МЕ/мл

Количество вещества (мг) = исходная концентрация (мг/мл) × исходный объём (мл)
Конечный объём (мл) = количество вещества (мг) / нужная концентрация (мг/мл)
Растворитель (мл) = конечный объём (мл) − исходный объём (мл)
Конечная концентрация (мг/мл) = количество вещества (мг) / конечный объём (мл)
```

Массовая концентрация задаётся в мг/мл, мкг/мл или процентах **масса/объём (г/100 мл)**. Для такого определения `1% = 10 мг/мл`. Проценты массовой или объёмной доли этим способом не пересчитываются. Количество вещества в исходном и целевом растворе должно быть указано по одной основе: например, оба значения по основанию либо оба по соли. Автоматического пересчёта основания в соль нет.

Для активности используется та же формула сохранения количества: `активность = концентрация × объём`, где обе концентрации относятся к одному препарату и выражены в одинаковых ЕД/мл либо МЕ/мл. Единицы выбираются по маркировке препарата. Например, в [официальном реестре Минздрава](https://pots.minzdrav.gov.ru/public_price_limits?page=271&per_page=45) гепарин указан в МЕ/мл, а [некоторые препараты инсулина](https://pots.minzdrav.gov.ru/public_price_limits?page=1362&per_page=15) — в ЕД/мл. Эти обозначения служат для ввода данных, а не для выбора препарата, дозы или способа введения.

Объём препарата входит в конечный объём: 4 мл исходного раствора + 46 мл растворителя = 50 мл готового раствора. Расчёт предполагает сложение объёмов. Нужная концентрация выше исходной и конечный объём меньше исходного отклоняются.

Калькуляторы выполняют арифметические операции по введённым данным. Доза, выбор растворителя, совместимость и правила приготовления определяются по инструкции к конкретному препарату и клинической ситуации.

Основания для коэффициентов пересчёта: [приставки СИ, BIPM](https://www.bipm.org/en/measurement-units/si-prefixes) и [единицы времени, NIST](https://www.nist.gov/pml/special-publication-330/sp-330-section-4). Формулы разведения выведены из сохранения количества вещества при добавлении растворителя.

## Проверка расчётов

Нужен Node.js 18 или новее. Установка зависимостей не требуется.

```bash
node --test tests/*.test.cjs
```

Тесты проверяют контрольные значения, все направления пересчёта, единицы активности и запрет смешивания несовместимых единиц, блокировку зависимых этапов, связанные поля, выбор исходного поля при изменении веса и концентрации, точность, ошибки ввода и недопустимость подмены очень малого положительного результата нулём.

Основные файлы: `assets/calculations.js` — чистые функции расчёта и состояния этапов; `assets/infusion.js` — единая форма скорости введения; `assets/numeric-input.js` — ограничения ввода; `assets/app.js` — приготовление растворов; `assets/styles.css` — общие стили.
